# NewProjects

Фаворит проекта — **библиотека соло-книг НРИ по подписке** («ИИ-геймбуки»): приложение, где ИИ генерирует книги-игры — текст с ветвлением по абзацам, статы, инвентарь, кубики, карты и иллюстрации. Исходный бриф (10 идей цифрового продукта на базе ИИ-агента) выполнен: идеи собраны в [`IDEAS.md`](IDEAS.md), выбран фаворит (D-015).

Репозиторий — не только место для файлов, но и **внешняя память проекта**: где мы находимся, что решили и почему, какие были проблемы и как их закрыли.

## Главное правило

Перед работой — прочитать память. После работы — обновить её и запушить.

Полный протокол: [`AGENTS.md`](AGENTS.md). Он обязателен для любого агента и человека, который здесь работает.

## Карта документов

| Файл | Что внутри | Как меняется |
|---|---|---|
| [`README.md`](README.md) | Входная точка и суть проекта | При изменении сути или структуры |
| [`STATUS.md`](STATUS.md) | Где мы сейчас: стадия, готово, в работе, следующий шаг, блокеры | Перезаписывается каждый ход |
| [`DECISIONS.md`](DECISIONS.md) | Журнал решений: что, когда, почему, альтернативы, последствия | Только дополняется |
| [`ISSUES.md`](ISSUES.md) | История проблем: симптом, причина, как решили, проверка | Только дополняется |
| [`ROADMAP.md`](ROADMAP.md) | Планы: сейчас / далее / позже / не делаем | Обновляется при смене приоритетов |
| [`IDEAS.md`](IDEAS.md) | Список идей продукта и их оценки | По мере генерации и отбора |
| [`PILOT.md`](PILOT.md) | Концепт пилотной книги-игры | По мере проектирования |
| [`AGENTS.md`](AGENTS.md) | Протокол ведения памяти и правила работы | При изменении процесса |

## Текущее состояние

**Стадия 2 — проектирование пилота.** Концепт лавкрафтовской книги-игры готов ([`PILOT.md`](PILOT.md)); утверждаем название и структуру, затем сборка MVP.

Актуальный снимок — в [`STATUS.md`](STATUS.md).

## Быстрый старт

1. Прочитать [`AGENTS.md`](AGENTS.md).
2. Прочитать [`STATUS.md`](STATUS.md), последние записи [`DECISIONS.md`](DECISIONS.md), открытые [`ISSUES.md`](ISSUES.md), [`ROADMAP.md`](ROADMAP.md).
3. Работать.
4. Перед финальным ответом обновить память и выполнить:

```powershell
.\scripts\sync.cmd -Message "docs: краткое описание изменений"
```
