# NewProjects

Фаворит проекта — **библиотека соло-книг НРИ по подписке** («ИИ-геймбуки»): приложение, где ИИ генерирует книги-игры — текст с ветвлением по абзацам, статы, инвентарь, кубики, карты и иллюстрации. Исходный бриф (10 идей цифрового продукта на базе ИИ-агента) выполнен: идеи собраны в [`IDEAS.md`](IDEAS.md), выбран фаворит (D-015).

Репозиторий — не только место для файлов, но и **внешняя память проекта**: где мы находимся, что решили и почему, какие были проблемы и как их закрыли.

## Главное правило

Перед работой — прочитать память. После работы — обновить её и запушить.

Полный протокол: [`AGENTS.md`](AGENTS.md). Он обязателен для любого агента и человека, который здесь работает.

## Быстрый старт

1. Прочитать [`AGENTS.md`](AGENTS.md).
2. Прочитать [`STATUS.md`](STATUS.md), последние записи [`DECISIONS.md`](DECISIONS.md), открытые [`ISSUES.md`](ISSUES.md), [`ROADMAP.md`](ROADMAP.md).
3. Работать.
4. Перед финальным ответом обновить память и выполнить:

```powershell
.\scripts\sync.cmd -Message "docs: краткое описание изменений"
```
