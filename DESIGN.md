# Дизайн игры v2 — эталон: Four Against Darkness

**Обновлено:** 2026-10-29  
**Статус:** разбор эталона выполнен; ждём подтверждения направления перед сборкой v2.

## Зачем этот документ

Прототип v1 (текст + кнопки + статы) признан владельцем слишком примитивным. Эталон качества — **Four Against Darkness** (4AD) Андреа Сфилигои: соло-данжен-кроулер с процедурной генерацией. Здесь — разбор 4AD и наш редизайн под цифровой формат.

## Что такое Four Against Darkness (разбор)

- **Партия из 4 героев**, классы: воин, клирик, вор, волшебник, эльф, гном, бард, варвар (8 классов).
- **Герой** = класс + уровень + 3 атрибута: **Атака, Защита, Жизнь** (HP). У монстров и ловушек — «уровень».
- **Генерация героя**: стартовые броски (золото, снаряжение, жизнь по классу).
- **Бой**: герои ходят первыми. Атака = `1d6 + модификаторы ≥ уровень монстра` → 1 урон. Миньоны — 1 HP, боссы — несколько HP. Защита = `1d6 + доспех(+1) + щит(+1) + уровень ≥ уровень монстра` → уклонение; промах = 1 урон. **6 «взрывается»** (переброс с плюсом).
- **Переговоры**: пропустить ход → таблица реакции монстров.
- **Магия**: волшебник `1d6 + уровень` против цели; заклинания ограничены (3 на приключение).
- **Данжен-генерация таблицами**: коридор (направление/длина), дверь, комната (размер/содержимое: монстр / ловушка / сокровище / пусто / особое), лестницы, босс.
- **Бродячие монстры**: проверка каждый ход (`1d6`).
- **Сокровища**: таблица с модификатором по типу монстра.
- **Прокачка**: убить босса / квест / пережить 10 стычек → бросок на уровень.
- **Карта рисуется вручную** — главная сложность 4AD; у нас она станет виртуальной.

## Что берём из 4AD (ядро)

1. Процедурный данжен-кроулер: каждая сессия = генерируемое подземелье.
2. Партия героев с простыми статами.
3. Бой `d6+мод vs уровень`, взрывной кубик, миньоны/боссы, уклонение.
4. Таблицы: комнаты, коридоры, монстры, ловушки, сокровища, бродячие монстры.
5. Прокачка и награды.

## Что делаем по-своему (требования владельца)

- **Виртуальная карта**: комнаты и коридоры генерируются и рисуются автоматически, объекты расставляются автоматически; движение — тап по соседней клетке/комнате (унифицировано, без ручного рисования).
- **Анимации**: кубики «падают», карты «вытягиваются» из колоды; бросок/тяга — только по нажатию кнопки.
- **Создание героя в начале**: броски кубиков/карт интерактивно задают базовые статы.
- **Лавкрафтовская тема**: добавляем **Рассудок** (sanity), полный набор кубиков d4–d100, колоду 52+джокеры+Таро.
- **Сюжетные книги-игры** остаются как жанровая обвязка (жанры как фильмы), но ядро — данжен-кроулер в духе 4AD.

## Игровой цикл v2

1. **Создание партии** — броски кубиков/карт задают статы героев.
2. **Вход в подземелье** — процедурная генерация (уровень, карта, босс).
3. **Ход** — движение по карте (тап) → событие комнаты/коридора (монстр / ловушка / сокровище / особое) → бой или проверка.
4. **Бродячие монстры**, сокровища, **босс**, выход/смерть, **прокачка**.

## Технический план

- Остаёмся на **vanilla JS + Canvas/SVG** (без сборщика, без Node) — карта на Canvas/SVG, анимации на CSS/JS.
- Данжен-генератор — отдельный модуль (таблицы из 4AD, адаптированные).
- Движок расширяем: анимированный бросок кубика, колода с анимацией вытягивания, взрывной d6.
- **Первый вертикальный срез v2**: генерация героя (броски) → карта (несколько комнат) → движение тапом → бой с анимированным кубиком.
