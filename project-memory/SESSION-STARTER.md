# Обновление сессии NewProjects

**Когда:** давление контекста ≥ 60%, сессия тормозит, или после крупного этапа.

## Порядок (важен именно такой)

1. **Сначала заархивируй старую сессию.** Archive, не Delete — её напоминания уйдут вместе с ней.
2. Открой **новый чат** в этой же рабочей папке (`C:\Users\monte\Downloads\NewProjects`).
3. Вставь промт ниже целиком.
4. Новая сессия сама прочитает этот файл и сделает всё по разделу «Что сделать».
5. Старую сессию удалить через неделю; история — в архиве.

## Промт (копировать целиком)

```text
Ты — новая главная сессия NewProjects. Прочитай SESSION-STARTER.md и выполни раздел
«Что сделать новой сессии» целиком, по порядку. Память — файлы в корне репозитория
(AGENTS.md, STATUS.md, DECISIONS.md, ISSUES.md, ROADMAP.md, README.md), текущий фокус —
в ROADMAP.md («Сейчас») и STATUS.md («Следующий шаг»).

Не пересказывай файлы. После каждого ответа обновляй память и пушь (scripts/sync.cmd).
Секреты — только в secrets.env (в .gitignore). Ничего не публикуй и никому не пиши без «да».
```

## Что сделать новой сессии

1. Прочитать: `AGENTS.md`, `STATUS.md`, последние 3 записи `DECISIONS.md`, открытые `ISSUES.md`,
   `ROADMAP.md`, `README.md`.
2. Проверить `git status` и `git pull` — репозиторий публичный, ветка `main`, `origin` настроен.
3. Свериться с `ROADMAP.md` → «Сейчас» и `STATUS.md` → «Следующий шаг» — это то, что делаем прямо сейчас.
4. Записать свой `DSH_SESSION_ID` в `project-memory/pressure.json` → `sessionId`
   (по нему вкладка «Давление» следит за главной сессией).
5. Правила работы — `AGENTS.md`: память после каждого ответа, пуш через `scripts/sync.cmd`,
   вкладки браузера закрывать, секреты не коммитить.

## Что важно

- Всё состояние — в файлах памяти; контекст переносить не нужно.
- `STATUS.md` — снимок (перезаписывается); `DECISIONS.md` и `ISSUES.md` — append-only.
- Игра живёт на https://montegorod.github.io/newprojects/ (деплой автоматический через GitHub Actions).
- Иллюстрации — `scripts/gen_images.py` (Replicate FLUX.1-dev, токен `REPLICATE_API_TOKEN` в `secrets.env`).
