# Стиль иллюстраций (гравюра) и список сцен

**Обновлено:** 2026-10-29  
**Статус:** сгенерировано 8/9 сцен через Replicate FLUX.1-dev (`scripts/gen_images.py`), без водяных знаков.

## Визуальный стиль

- **Техника:** тёмная гравюра / чернила (woodcut/etching): плотная штриховка, высокий контраст, глубокие тени.
- **Цвет:** чёрно-белый + один акцентный цвет — глубокий сине-зелёный `#2f7f7f`. Без текста, без водяных знаков.
- **Палитра:** фон `#0c0e12`, чернила `#d8d2c4`, акцент `#2f7f7f`.

## Шаблон промпта (стиль-карточка)

```
Dark woodcut engraving, [SCENE], Lovecraftian coastal horror,
black and white with a single deep teal accent, heavy crosshatching,
dense shadows, atmospheric, cinematic framing, no text, no watermark, no signature.
```

## Технические заметки

- Файлы в `web/content/img/` (`.jpg`, 1024×1024).
- Генерация: `python scripts/gen_images.py` (Replicate `black-forest-labs/flux-dev`, токен `REPLICATE_API_TOKEN` в `secrets.env`).
- Replicate без платёжного метода лимитирует ~6 запросов/мин — поэтому `trap.jpg` не успел; догенерировать отдельным запуском.
- Подключение в игре: обложка — `index.html` (`#cover`), монстры — `app.js` (`MONSTER_IMG`).
